# Paradise Nursery - e-plantShopping

**e-plantShopping** is a responsive e-commerce web application designed for plant lovers to browse, select, and purchase indoor houseplants online from **Paradise Nursery**.

## Repository Details

- **Project Name**: Paradise Nursery Shopping Application
- **Repository Name**: `e-plantShopping`
- **GitHub Repository**: [https://github.com/PrathameshSJ/e-plantShopping](https://github.com/PrathameshSJ/e-plantShopping)

---

## Features

- **Landing Page**:
  - Immersive background image and company overview for Paradise Nursery.
  - "Get Started" call-to-action button transitioning smoothly to the plant store.
- **Plant Catalog**:
  - Categorized plants across multiple categories including Air Purifying Plants, Aromatic Fragrant Plants, Insect Repellent Plants, Medicinal Plants, and Low Maintenance Plants.
  - At least 6 unique houseplants per category with thumbnail images, names, descriptions, and prices.
  - Interactive "Add to Cart" buttons that update the cart and disable upon addition.
- **Shopping Cart**:
  - Dynamic shopping cart badge displaying the total number of items in real-time.
  - Cart page showing total cart cost, unit prices, subtotal per plant, thumbnail, and plant name.
  - Increment and decrement quantity controls with dynamic total calculation.
  - Item deletion button.
  - "Continue Shopping" button returning to the product catalog.
  - "Checkout" button with "Coming Soon" notification.
- **Navigation**:
  - Unified navbar visible across both Product Listing and Shopping Cart views with links to Home, Plants, and Cart.

## Installation & Setup

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/PrathameshSJ/e-plantShopping.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd e-plantShopping
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Build for production**:
   ```bash
   npm run build
   ```
